# /portfolio

## 목적

`reports/positions.md`에 기록된 "보유중" 포지션 전체가 지금 실시간 시세 기준으로 얼마나 벌고/잃고 있는지, 계좌 전체 리스크(포트폴리오 히트)는 얼마인지 한눈에 보여준다.

**핵심 차이 — 다른 스킬과 비교**: 이 스킬은 주관적 판단이 필요 없는 순수 집계·계산이다. 그래서 `/trade-team`·`/position-review`처럼 에이전트가 여러 판단을 내리지 않고, `tools/portfolio_dashboard.py` 스크립트 하나를 실행해 이미 계산된 결과를 표로 정리해 보여주기만 한다. 티커마다 개별적으로 Bash를 호출하지 않는다 (비용·속도 모두 불리하기 때문).

## 입력

```
/portfolio
```

인자가 없다. 항상 `reports/positions.md`의 "보유중" 상태 행 전체를 대상으로 한다.

## 실행 순서

1. `python tools/portfolio_dashboard.py`를 실행한다 (실행 전 `pip install -r requirements.txt`가 안 되어 있으면 먼저 설치를 안내한다).
2. 스크립트 출력(JSON)을 그대로 파싱해서 아래 출력 포맷의 표로 옮긴다 — 값을 암산하거나 다시 계산하지 않는다.
3. `errors` 배열에 항목이 있으면(시세 조회 실패 등) 해당 티커를 표에서 "조회 실패"로 표시하고, 사유를 함께 보여준다. 나머지 포지션은 정상적으로 계속 표시한다 (부분 실패가 전체를 막지 않는다).
4. `portfolio_heat`가 `null`이면(보유 포지션 없음) 히트 섹션을 생략하고 안내 문구만 남긴다.

## 출력 포맷

```
# /portfolio 대시보드 (<조회 시각>)

## 보유 포지션 (<n_quoted>/<n_positions>개 시세 조회됨)
| 티커 | 진입가 | 현재가 | 손절가 | 목표가 | 방향 | 미실현 수익률 | 미실현 R-멀티플 | 상태 |
|---|---|---|---|---|---|---|---|---|
| AAPL | 200 | 220.00 | 190 | 260 | long | +10.00% | +2.00R | profit |

## 조회 실패
- BADCO: 'BADCO'의 현재가를 조회하지 못했습니다: ...
(실패 없으면 이 섹션 생략)

## 포트폴리오 히트
| 보유 포지션 수 | 합산 리스크% | 한도 | 초과 여부 |
|---|---|---|---|
| 2 | 3.5% | 6% | 아니오 |
(경고가 있으면 그 내용도 함께 표시)
```
