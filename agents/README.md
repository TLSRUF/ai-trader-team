# agents/

이 폴더는 스킬이 병렬로 호출하는 **에이전트 페르소나 정의**를 담습니다. 각 파일은 하나의 관점(역할)을 나타내며, 서로 다른 판단 기준을 갖도록 설계해 의견 충돌 자체가 정보가 되게 합니다.

## 규칙

- 파일명 = 역할 슬러그 (예: `trend-analyst.md`, `risk-manager.md`)
- 각 에이전트 정의는 다음을 포함해야 함:
  - 담당 관점 / 핵심 질문
  - 리서치 시 우선순위로 보는 데이터
  - 평가 기준 (아래 공통 척도 사용)
  - 출력 포맷 (team-lead에게 보고하는 구조)
- 실제 실행은 스킬(`skills/*.md`)이 서브에이전트(Task 도구 등)를 병렬로 띄우면서 이 정의를 프롬프트로 주입하는 방식으로 이루어짐.

## 공통 점수 척도

모든 에이전트는 아래 척도를 공유해서, team-lead가 서로 다른 관점의 점수를 한 표에 나란히 놓고 비교할 수 있게 합니다.

| 점수 | 의미 |
|---|---|
| 0~1 | 명확히 부정적 (진입 근거 없음) |
| 2 | 약함 / 근거 부족 |
| 3 | 중립 / 판단 보류 (Gray Zone) |
| 4 | 긍정적 |
| 5 | 강한 확신 |

각 에이전트는 점수와 함께 **Bull / Bear / Neutral** 결론 태그를 함께 출력합니다. 여러 에이전트의 태그가 갈리는 경우, 이는 오류가 아니라 "지금은 그레이존"이라는 유의미한 신호로 취급합니다.

## 데이터 신뢰도 표기 (핵심 수치 단위)

보고서 끝에 "데이터 신뢰도" 한 줄만 붙이면, 정작 어떤 근거가 부실한지 리포트를 읽는 사람이 알 수 없습니다. 그래서 각 에이전트는 "근거"/"반증"/"실패 시나리오"에 적는 구체적 수치·사실 **하나하나**에 아래 등급을 태깅하고, 보고서 끝의 "데이터 신뢰도" 줄은 감으로 다시 판단하지 않고 그 태그들을 집계해서 채웁니다.

| 태그 | 의미 |
|---|---|
| 🟢 | 1차/공식 출처, 최신 데이터로 확인 |
| 🟡 | 2차 출처이거나 다소 지연된 데이터 |
| 🔴 | 추정치이거나 확인 안 됨 |

- **표기**: 각 bullet 끝에 태그를 붙입니다 (예: `- RSI 68, 상대강도 상위 10% 🟢`).
- **집계**: "데이터 신뢰도" 줄은 `🟢 N개 / 🟡 N개 / 🔴 N개 — 종합: <등급>` 형태로 씁니다. **종합 등급은 가장 약한 고리 기준**입니다 — 하나라도 🔴 태그가 있으면 종합도 🔴로 표기하고(평균으로 완화하지 않음), 🔴가 없고 🟡가 하나라도 있으면 🟡로 표기합니다.
- team-lead가 여러 에이전트 보고서를 종합할 때도 이 집계 줄들을 다시 합산해서 전체 신뢰도를 산출합니다 — 개별 눈대중 요약으로 대체하지 않습니다.
