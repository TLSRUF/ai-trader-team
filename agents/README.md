# agents/

이 폴더는 스킬이 병렬로 호출하는 **에이전트 페르소나 정의**를 담습니다. 각 파일은 하나의 관점(역할)을 나타내며, 서로 다른 판단 기준을 갖도록 설계해 의견 충돌 자체가 정보가 되게 합니다.

## 규칙

- 파일명 = 역할 슬러그 (예: `trend-analyst.md`, `risk-manager.md`)
- 각 에이전트 정의는 다음을 포함해야 함:
  - 담당 관점 / 핵심 질문
  - 리서치 시 우선순위로 보는 데이터
  - 평가 기준 (아래 공통 척도 사용)
  - 출력 포맷 (team-lead에게 보고하는 구조)
- 실제 실행은 스킬(`skills/*.md`)이 서브에이전트(Task 도구 등)를 병렬로 띄우면서 이 정의를 프롬프트로 주입하는 방식으로 이루어짐.

## 공통 점수 척도

모든 에이전트는 아래 척도를 공유해서, team-lead가 서로 다른 관점의 점수를 한 표에 나란히 놓고 비교할 수 있게 합니다.

| 점수 | 의미 |
|---|---|
| 0~1 | 명확히 부정적 (진입 근거 없음) |
| 2 | 약함 / 근거 부족 |
| 3 | 중립 / 판단 보류 (Gray Zone) |
| 4 | 긍정적 |
| 5 | 강한 확신 |

각 에이전트는 점수와 함께 **Bull / Bear / Neutral** 결론 태그를 함께 출력합니다. 여러 에이전트의 태그가 갈리는 경우, 이는 오류가 아니라 "지금은 그레이존"이라는 유의미한 신호로 취급합니다.

## 현재 정의된 페르소나

트레이딩 관점 4종 — 서로 다른 시간축·데이터·판단 기준을 갖도록 설계했습니다.

| 파일 | 관점 | 핵심 질문 |
|---|---|---|
| [`trend-analyst.md`](trend-analyst.md) | 모멘텀 / 추세 | 지금 추세를 따라야 하는가? |
| [`macro-analyst.md`](macro-analyst.md) | 매크로 / 거시 | 지금이 이 자산군에 우호적인 매크로 환경인가? |
| [`risk-manager.md`](risk-manager.md) | 리스크 관리 | 무엇이 틀릴 수 있고, 얼마나 잃을 수 있는가? |
| [`flow-analyst.md`](flow-analyst.md) | 유동성 / 수급 | 지금 누가 사고, 누가 파는가? |
