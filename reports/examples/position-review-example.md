# /position-review 리포트 — DEMO-A (2026-09-05, 예시)

## 최초 테제 요약

출처: [`trade-team-example.md`](trade-team-example.md) (2026-08-22)

- 추세 Bull(4/5), 매크로 Neutral(3/5), 수급 Bull(4/5) — 3개 관점 긍정적
- 리스크 Bear(2/5) — 상관관계 높은 기존 포지션, 큰 MDD 이력을 근거로 반대 → **Gray Zone** 판정
- 공격적 전략으로 진입: 진입 50 / 손절 45 / 목표 65 (risk-reward 3.00)

## 관점별 드리프트

| 관점 | 최초 판단 | 현재 판단 | 드리프트 |
|---|---|---|---|
| 추세 | Bull (4/5) | Bull (3/5) | 약화 — 상승 배열은 유지되나 상대강도가 추가로 둔화됨 |
| 매크로 | Neutral (3/5) | Neutral (3/5) | 동일 — 섹터 로테이션 방향 여전히 상충 |
| 리스크 | Bear (2/5) | Bear (1/5) | 약화 — 최초 우려했던 상관관계 포지션에서 실제로 손실이 발생, 계좌 전체 여력 축소 |
| 수급 | Bull (4/5) | Neutral (2/5) | **반전** — 순매수 흐름이 순매도로 전환, 이상거래량 신호 소멸 |

## 종합 드리프트 심각도

**심각** — 수급 관점이 Bull→Neutral로 반전됐고, 리스크 관점(가중치 높음)도 최초 우려가 실제 손실로 현실화되며 추가 약화됨. 3개 관점이 긍정적이었던 최초 구도가 무너짐.

## 대응 제안

**축소 검토** (전량 청산까지는 아니나, 포지션 절반 이상 축소를 권장)

- 근거: 최초 테제를 지탱하던 두 축(추세 강세 + 수급 매수세) 중 수급이 반전됐고, 리스크 관리자가 우려한 상관관계 리스크가 실제 손실로 확인됨. 추세는 아직 완전히 무너지지 않았으므로(Bull 유지) 전량 청산보다는 비중을 줄여 손절 여력을 넓히는 쪽이 합리적.
- 손절선 재확인: 최초 손절 45는 유지하되, 축소 후 잔여 포지션 기준으로 `tools/trading_rigor.py risk-reward`를 다시 계산해 목표가 대비 비율을 재검증할 것.

```
$ python tools/trading_rigor.py risk-reward --entry 50 --stop 45 --target 65
{
  "direction": "long",
  "risk": "5",
  "reward": "15",
  "risk_reward_ratio": "3.00"
}
```

(축소 후에도 진입/손절/목표 가격 자체는 불변이므로 비율은 동일 — 변하는 것은 포지션 크기와 계좌 전체 리스크 노출)
